# Manuscript campaign inventory

This document records the public-facing structure of the final numerical
campaigns. Machine-readable configuration files are the execution authority;
this document is an overview.

## Parameter sensitivity

All four nominal tasks are evaluated with 20 seeds, `71000--71019`.

- inverse-temperature multipliers: `0.25, 0.5, 1, 2, 4, 8`;
- normalized drift-diffusion values: `0.1, 0.3, 0.5, 0.7, 0.9`;
- the shared nominal point is deduplicated;
- each task has 22 executable cells across its two temperatures;
- expected total: 1760 trajectories and 1760 metric records.

The nominal rollout budgets and task-specific local perturbation covariances are
unchanged. The campaign uses a fixed common-noise evaluation seed independent
of its controller seeds.

## Landscape and diagnostic calculations

### Navigation

The open-loop route family and projected free-energy landscape use fixed route
construction, perturbation covariance, temperatures, and random seeds. These
calculations do not depend on a private result directory.

### Pendulum

The pendulum landscape is recomputed from the public dynamics, cost, trajectory
template, and fixed Monte Carlo inputs. Frozen arrays are retained only for the
fast figure-replay path.

### Planar Arm

The planar-arm landscape uses:

- controller horizon 20;
- a 60-step base closed-loop execution generated by the nominal public runner;
- diagnostic horizon 60;
- temperatures 3 and 300;
- 61 values over `[-0.3, 0.3]`;
- 1024 local samples;
- perturbation standard deviation 0.03;
- temporal correlation 0.81;
- random seed 27200.

The landscape stage consumes the base trajectory from the same public run. It
does not fetch a trajectory from a historical checkout.

## Timing exclusion

No timing-selection or control-cycle timing campaign is run. The final budgets
listed above are fixed inputs. This exclusion does not remove any trajectory,
free-energy, sensitivity, horizon, or landscape computation used to generate
the nine manuscript figures.
